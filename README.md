## The entry

> "I graded it first — every answer was wrong, so I ate the evidence before the teacher saw it. You're welcome."

One line, in the dog's own voice, caught in the act — a dog who graded the homework, found every answer wrong, and ate the evidence as a favour. No embarrassment, no apology, just a job well done.

## How it works

`main.ts` is fully deterministic — no network, no randomness, no time dependence. It writes the single entry line to `/output/entry.txt` (one line, no trailing newline). Run it twice and the output is byte-identical.
